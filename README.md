# PSD_eNGINNo Chiller Plant Analytic System

เว็บแอปวิเคราะห์ Chiller plant (Chiller / CHP / CDP / Cooling tower) จากไฟล์ Excel log รายเดือน
ไฟล์เดียว `index.html` เปิดใช้งานได้เลย ไม่ต้องมี server

## ฟีเจอร์
- Login / Register: ผู้ลงทะเบียนต้องให้ผู้ดูแล (admin) อนุมัติก่อนใช้งาน
- ภาพรวม: kW/TRp, kWh ทั้ง plant (kW × 2 ชม./บันทึก), เทียบเกณฑ์ประสิทธิภาพ, แนวโน้มรายเดือน
- วิเคราะห์รายตัวรายเดือน: Chiller, CHP, CDP, Cooling tower
- ก่อน–หลังปรับปรุง พร้อมผลประหยัดเทียบ baseline
- Chiller ดีที่สุดรายเดือน / ชุดอุปกรณ์ kW/TRp ต่ำสุด / Regression (R² > 80%, P < 0.05)
- ธีมพื้นหลัง 3 แบบ (เทา-ขาว, มืด, ฟ้าทะเล) และสีตัวอักษร 3 แบบ (ดำ, ส้ม, น้ำเงิน) ที่หน้า "ข้อมูลและการตั้งค่า" และฟอนต์ (Orbitron, Courier New, Sarabun, หรือค่าเริ่มต้น IBM Plex Sans Thai)
- เมนู "ความผิดปกติของข้อมูล" (กลุ่มการวิเคราะห์): แจ้งเตือนค่าผิดปกติ รายการวันที่-เวลา-ชุด และย้ายไป History เมื่อช่างแก้ไขแล้ว พร้อมบันทึกรายละเอียดการแก้ไข · หน้าอื่นมีแถบเตือนสั้นและป้าย ⚠ บนตาราง
- โหมดคำนวณหน้าภาพรวม: "เฉพาะค่าปกติ" หรือ "รวมทั้งหมด" (วิธีเดียวกับ dashboard) เลือกที่หน้าข้อมูลและการตั้งค่า · kWh นับทุกบันทึกในทั้งสองโหมด
- หน้า "ข้อมูลและการตั้งค่า": ดูรายการวันที่-เวลา-ชุดที่ถูกตัดออกจากการวิเคราะห์ พร้อมบอกว่าสูง/ต่ำกว่าช่วง, เทียบค่าเฉลี่ยกับ dashboard, ดาวน์โหลดเป็น Excel
- นำเข้าข้อมูลรายเดือนจาก .xlsx หรือ **วางข้อมูลที่คัดลอกจาก Google Sheet** (เฉพาะ admin) / ส่งออกรายงาน HTML และ Excel

## วางข้อมูลจาก Google Sheet
ปุ่ม "นำเข้าข้อมูล" → แท็บ "วางจาก Google Sheet" → ใน Sheet คลิก A1, Ctrl+A, Ctrl+C แล้ววางในช่อง (ต้องมีแถวหัวคอลัมน์)
ไม่ต้องเชื่อม Google Drive แอปอ่านเฉพาะข้อความที่วาง

## เผยแพร่ด้วย GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)`

## แก้ไขโค้ด
แก้ไฟล์ใน `src/` แล้วรัน `python3 build.py` เพื่อสร้าง `index.html` ใหม่

## ข้อจำกัดด้านความปลอดภัย (สำคัญ)
- ระบบ Login ทำงานในเบราว์เซอร์ทั้งหมด เป็นเพียงด่านกั้นสำหรับทีมขนาดเล็ก **ไม่ใช่ความปลอดภัยระดับเซิร์ฟเวอร์**
  ใครเปิดดูซอร์สหรือ DevTools ได้ก็เห็นข้อมูลตั้งต้น (`src/seed.json`) และ hash ของรหัสผ่าน admin ได้
- บน GitHub Pages รายชื่อผู้ใช้เก็บใน IndexedDB ของแต่ละเบราว์เซอร์ ผู้ลงทะเบียนบนเครื่องหนึ่งจึงไม่ไปปรากฏที่ admin บนอีกเครื่อง
  ถ้าต้องการอนุมัติข้ามเครื่องจริง ต้องเพิ่มฐานข้อมูลฝั่งเซิร์ฟเวอร์ (เช่น Firebase / Supabase)
- ใช้ repo แบบ Private ถ้าข้อมูล log เป็นความลับ และเปลี่ยนรหัสผ่าน admin ด้วย `tools/make_admin_hash.py`
